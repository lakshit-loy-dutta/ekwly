## 1. Confirmed Technology Stack & Database State (`schema_dump_3.sql` + Migration #4)

- **Frontend Framework:** Astro 7 (`^7.3.8`, static output) + React 19 (`^19.3.0`, `React.lazy` route splitting + `swrCache.ts` 0ms tab state cache + `createPortal` modals) + TypeScript (`^7.0.2`).
- **Styling & Motion:** Tailwind CSS v4 (`^4.3.3` via `@tailwindcss/vite`, `@layer base` form reset) + Framer Motion (`^13.5.1`) + Lucide React (`^1.56.0`).
- **Backend & Database:**
  - Tables: `sessions`, `items`, `members`, `claims`, `tax_presets`, `ledger`, `profiles`, `connections`, `venues`.
  - Views: `global_ledger`, `personal_analytics`.
  - Security Triggers & Functions:
    - `public.enforce_session_lock_integrity()`: Blocks any `INSERT`, `UPDATE`, or `DELETE` on `items`, `claims`, and `tax_presets` when a session's `status = 'locked'`.
    - `public.protect_profile_billing_columns()`: Prevents client-side tampering with `pro_expires_at` and `ai_scans_used`.
    - `public.harvest_venue_data()`, `public.prune_stale_data()`, `public.search_venues()`, `public.search_venue_items()`, `public.verify_session_pin()`, `public.delete_user_account()`.
  - Granular RLS Policies: Host-only session deletion/updates, Host-only item/tax mutations, participant-only ledger settlement updates, and identity-spoofing protection on `members`.
  - Indexes: All 14 B-Tree foreign-key/partial indexes and `pg_trgm` GIN indexes (`idx_venues_name_trgm`, `idx_profiles_name_trgm`, `idx_connections_unique_pair`) are active.
- **AI Vision OCR (`supabase/functions/scan-receipt/index.ts` Deployed):** `gemini-3.5-flash-lite` with Chain-of-Thought `reasoning` verification and 3-layer discount extraction.
